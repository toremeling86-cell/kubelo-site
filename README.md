# Kube

En 3D-puslekube som svever over skyene. Åpne https://kubelo.app/ på telefonen og legg den til på
startskjermen.

Dette repoet inneholder bare det ferdige, minifiserte bygget som publiseres med GitHub Pages. Kildekoden er privat.
Lisensene for bibliotekene og skriftene appen bruker, står i [lisenser.txt](play/lisenser.txt).
